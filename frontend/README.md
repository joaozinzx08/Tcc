# Resolva Já

Frontend do sistema de reclamações "Resolva Já" — TCC do curso de Desenvolvimento de Sistemas.

## Rodando o projeto

```bash
npm install
npm run dev
```

## Stack

- React 18 + JavaScript (sem TypeScript)
- Vite
- React Router
- Tailwind CSS
- lucide-react (ícones)

## Estrutura

- `src/pages` — telas da aplicação
- `src/components` — componentes reutilizáveis
- `src/data/mockData.js` — dados fictícios usados enquanto o backend não está integrado
